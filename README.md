# 🤖 Robotics for Beginners – Free Online Course

Welcome to **Robotics for Beginners**, a free online course designed for students, hobbyists, and technology enthusiasts who want to learn the fundamentals of **Robotics**, **IoT**, and **Arduino Programming**.

This course provides a step-by-step introduction to basic electronics, programming, and robotics project development using the Arduino platform.

## 📚 Course Modules

### Module 1: Introduction to Robotics and IoT

* What is Robotics?
* Introduction to IoT
* Applications of Robotics and IoT

### Module 2: Introduction to Arduino

* Arduino Board Structure
* Arduino IDE Setup
* Arduino Software Structure

### Module 3: Arduino Basic (output) Programming

* Digital Output – LED Blinking (Part 1)
* Digital Output – LED Blinking (Part 2)

### Module 4: Arduino Basic (input) Programming

* Digital Input – Push Button
* Digital Input - Switch Control 

### Module 5: Arduino Core (analog) Programming
  
* Analog Output
* Analog Input
  
### Module 6: Arduino Communication   
* Serial Communication
* one wire Communication
  
### Module 7: Sensors for Arduino 

 * LDR Sensors Module
 * IR Sensor Module
 * Temperature Sensor Module
 * Ultrasonic Sensor Module

### Module 8: Display for Arduino 

 * 7 Segment Display Module
 * LCD Display Module
 * TFT Display Module  

### Module 9: Motor Control

 * DC Motor Control
 * Servo Motor Control
 * Stepper Motor Control
   
### Module 10: Robor Car Preparation  
* Introduction to Robot Car structure
* Build and assemble a 4WD (Four Wheel) robot car
* Wiring and motor connection setup
* Control using remote (IR / Bluetooth)
